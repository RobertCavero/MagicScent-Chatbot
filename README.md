# Magic Scent Chatbot: Recomendação Inteligente de Produtos

## 🎯 Sobre o Projeto

Este repositório contém a documentação e a implementação de um **Chatbot com Inteligência Artificial** focado na **Recomendação de Produtos e Assistência Virtual** para consulta de estoque, denominado *Magic Scent*. O principal objetivo é transformar a experiência do usuário no setor comercial, utilizando soluções inteligentes para inovar a interação dos consumidores com o mercado de perfumes. O software foi desenvolvido para suprir a demanda por ferramentas capazes de interpretar eficientemente as preferências olfativas dos usuários.

O projeto aborda tanto a perspectiva técnica da estrutura e dos recursos utilizados quanto as funcionalidades e diferenciais do programa, desde o planejamento até a implementação para potenciais usuários.

## ✨ Funcionalidades Principais

O Magic Scent Chatbot opera através de um **fluxo de perguntas e respostas** para guiar a interação, utilizando inteligência artificial em diversas etapas do atendimento.

1.  **Assistente Virtual e Coleta de Dados:** Recebimento inicial de dados (como o nome do usuário) e solicitação de uma descrição detalhada do perfume desejado.
2.  **Recomendação Inteligente (Mistral IA):** Consulta aos dados de perfumes disponíveis e geração de uma resposta formatada e contextualizada, seguindo regras predefinidas.
3.  **Processamento de Feedback:** O chatbot solicita o *feedback* do usuário sobre a sugestão gerada, permitindo ramificações no fluxo de conversa.
4.  **Recalculando Rotas (Google Gemini):** Em casos de reprovação da sugestão, o fluxo permite ao usuário reentrar com a descrição ou optar por uma consulta processada pelo **Google Gemini**, buscando maximizar a satisfação.
5.  **Aprimoramento Contínuo:** A lógica de interações e o design das respostas priorizam a precisão e a confiabilidade, refletindo o valor de **excelência técnica** e **evolução contínua** do projeto.

## 💻 Tecnologias e Recursos Utilizados

O desenvolvimento e a execução do projeto foram baseados na integração de plataformas e modelos avançados de IA:

| Tecnologia | Finalidade |
| :--- | :--- |
| **Typebot** | Plataforma de desenvolvimento e execução do chatbot assistente. O ambiente do editor do Typebot refere-se a configurações de fluxo como `FlowThemeSettings`. |
| **Mistral IA** | Utilizada para gerar a resposta inicial e a sugestão de perfume, consultando dados de estoque. |
| **Google Gemini** | Integrada para processar descrições mais complexas quando o usuário opta por uma consulta expandida ("consultar a internet"). |
| **APIs** | Utilizadas para integração segura com serviços externos e bibliotecas online. |

O chatbot funciona de modo **online**, isto é, exige conexão com a internet.
